# Northwind Robotics — Регламент выпуска обновлений

_Последнее обновление: 14.02.2026. Владелец: Инженерия платформы._

## Каналы прошивки

- Канал `stable` получает обновления **раз в квартал**, после полного цикла
  регрессионного тестирования на стенде.
- Канал `edge` получает обновления **каждую неделю** и предназначен для
  клиентов, которые хотят получать новые функции раньше.

Клиент может в любой момент перевести совместимый манипулятор с `edge` обратно
на `stable`.

## Релизы AtlasControl

Плановые релизы AtlasControl выходят по **вторникам**. Каждый релиз должен
пройти code review двух инженеров и автоматические тесты. В последние **2
недели декабря** действует заморозка изменений: выпускаются только исправления
критичных ошибок.

## Срочные исправления (hotfix)

Hotfix выпускается вне графика, если ошибка вызывает инцидент Sev 1 у
клиента. Его одобряют дежурный инженер и руководитель разработки; после выпуска
в течение 5 рабочих дней пишется разбор инцидента (postmortem).

## Откат

Если после релиза растёт число ошибок, дежурный инженер откатывает релиз на
предыдущую версию без дополнительных согласований. Откат должен занимать не
более 15 минут.
